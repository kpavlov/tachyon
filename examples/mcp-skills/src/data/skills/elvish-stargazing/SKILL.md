# Elvish Stargazing

Create harmless fictional star-reading scenes for fantasy stories and games.

## Reading

1. Ask what question or moment the character seeks guidance for.
2. Choose one constellation with an original Elvish-sounding name.
3. Describe how it shifts, brightens, or dims in the telling.
4. Offer a gentle, open-ended omen the character can interpret for themselves.

Never predict real-world events or present the reading as genuine fortune-telling.
