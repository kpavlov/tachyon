# Elvish Healing

Create harmless healing scenes for fictional worlds.

## Healing

1. Ask what troubles the character and where the scene takes place.
2. Read [the healer's book](references/HEALERS-BOOK.md).
3. Choose one fitting remedy from the book.
4. Describe the preparation, comforting effect, and gradual recovery.

Keep every remedy fictional. Never present it as real medical advice.
