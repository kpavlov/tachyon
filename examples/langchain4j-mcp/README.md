# LangChain4j MCP Example

Demonstrates Tachyon's `LangChain4jAnnotationProvider`: a plain LangChain4j `@Tool`-annotated
method — no Tachyon imports in `OrderService` at all — scanned into a running MCP server, taking
and returning composite (record) types.

## Features

- **Tool**: `placeOrder` — accepts a `PlaceOrderRequest` record (customer + a list of `OrderItem`
  records) and returns an `OrderConfirmation` record with computed totals. The input schema is
  generated by LangChain4j's own `ToolSpecifications` (records, nested objects, and lists — not
  just scalars); the response comes back as real `structuredContent`, not a stringified object.

## Quickstart

```shell
./mvnw package && \
java -jar target/langchain4j-example.jar
```

`tachyon-annotations-langchain4j` hasn't shipped in a Tachyon release yet, so building this
example against a published Tachyon version isn't possible until it does. Until then, install the
Tachyon reactor's SNAPSHOT locally first:

```shell
# from the repo root
./mvnw install -pl tachyon-api,tachyon-core,integrations/tachyon-annotations-langchain4j -am -DskipTests
```
